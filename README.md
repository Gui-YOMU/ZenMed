# ZenMed

Application web progressive pour consigner localement les prises de médicaments.

## Prérequis

- Node.js LTS
- npm

## Développement

```powershell
npm install
npm run dev
```

## Vérifications

```powershell
npm run lint
npm run build
```

Les icônes PWA sont placées dans `public/icons` :

- `icon-192.png`
- `icon-512.png`
